# 功能说明

## 三个界面

- **收缩条**：常驻在工作区顶部，鼠标停留约 0.35 秒后展开。
- **剪贴板面板**：显示最近 20 条文本；列表行使用透明内容和分隔线，选中项使用白色边框。
- **八方向网格**：按住 `Alt+V` 在鼠标处弹出。原来的 3×3 坐标保留，但中心格是取消区，不显示也不可选。

三个界面共用同一套自绘玻璃材质：屏幕背景捕获、真高斯模糊、调色和圆角高光。生产路径不使用折射，以避免彩色条纹。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Alt+V`（按住） | 打开网格，移动到方向后松开完成粘贴 |
| `Esc` | 取消当前网格选择 |
| `Ctrl+Alt+G` | 打开/隐藏玻璃调参面板 |
| `Ctrl+Alt+Q` | 退出程序 |

点击面板条目只会写回剪贴板；程序不会改变原窗口焦点，也不会自动模拟 `Ctrl+V`。在原窗口自行粘贴，可以避免干扰正在进行的工作。

## 数据与隐私

历史最多保存 20 条文本，只存在当前进程内存中。程序退出后自动清空，不写入历史数据库，不上传网络，不与其他用户共享。玻璃参数单独保存在 `%LocalAppData%\ClipDesk\glass.json`。

## 已知限制

首版优先验证完整交互闭环，以下项目留作后续兼容性工作：

- 显示器物理尺寸标定无法仅靠 Windows DPI 在所有设备上精确保证；
- 混合 DPI、多显示器、远程桌面和旧 DWM 环境尚未覆盖全部组合；
- 鼠标隐藏使用系统级光标替换，程序异常终止时仍需要继续加强恢复保护；
- 玻璃效果会随用户桌面背景变化，这是自绘背景捕获的预期表现。
